### Added

- AppImage for x86_64 Linux, with a Russian interface, system tray, optional autostart, and light and dark themes.
- Manual and automatic sorting of completed files across multiple input folders, with editable categories, exclusions, ordered rules, and per-folder options for automation and new arrivals.
- A review queue with batch move confirmation, JSON settings import and export, and local history with individual undo.
- Stable AppImage update metadata for external managers such as Gear Lever.

Destinations are subfolders of the source on the same filesystem. Settings and history are saved separately from the AppImage. The release includes SHA-256 checksums, the source commit, the Cargo lockfile, and packaging tool provenance.
