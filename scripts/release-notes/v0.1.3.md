### Changed

- Background startup now loads the tray and sorter without opening the main window. Closing an idle window releases its interface while automatic sorting continues. Reopening the queue shows the latest files and history.
- Background checks send only tray status while the window is unloaded. An open editor or pending selection retains its window so work can resume.

The release includes the x86_64 AppImage, its update index, SHA-256 checksums, the source commit, the Cargo lockfile, and packaging tool provenance.
