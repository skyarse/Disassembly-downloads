### Added

- Dolphin can open the original page or direct link for a file recorded by the companion browser extension.
- The Firefox extension lists files downloaded from the current page and can select them in Dolphin. The list follows moves performed by Downloads Triage and indicates when a file is unavailable.
- Browser integration is available under **Settings → Download sources**. Firefox supports temporary installation of the bundled extension. Chrome and Chromium support loading their bundled extension unpacked.

### Changed

- The queue window runs in a separate process. Closing it frees its memory while the tray and automatic sorting continue to run.

The release includes the x86_64 AppImage, its update index, SHA-256 checksums, the source commit, the Cargo lockfile, and packaging tool provenance.
